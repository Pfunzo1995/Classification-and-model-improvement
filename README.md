# Classification-and-model-improvement
Breast classification using machine learning
Project Overview

This project uses machine learning to classify breast cancer tumours as benign or malignant using the Breast Cancer Wisconsin (Diagnostic) dataset.

Objectives

Explore and understand the dataset.

Prepare the data for classification.

Select relevant features.

Train a Logistic Regression classification model.

Evaluate the model using appropriate performance metrics.

Discuss limitations and recommend possible improvements.

Dataset

The Breast Cancer Wisconsin (Diagnostic) dataset is provided by scikit-learn. It contains 569 samples, 30 numerical features and a target indicating whether a tumour is malignant or benign.

Methodology

Data loading and inspection.

Exploratory data analysis.

Data preprocessing and feature selection.

Training and testing the classification model.

Evaluating model performance using a confusion matrix, accuracy, precision, recall and F1-score.

Discussing results and limitations.

Tools

Python

Jupyter Notebook

pandas and NumPy

Matplotlib

scikit-learn

Files

Cancer_Classification.ipynb: Python code, visualisations and model results.

Cancer_Classification_Report.pdf: Written report and references.

Important Note

This project is an educational machine learning exercise. The model is not intended to replace professional medical diagnosis.
